# فواتير Paydo

التطبيق يفتح بوابة Paydo ويحفظ جلسة الدخول، ثم يسترجع حتى 500 فاتورة عند تشغيله لتغطية الفواتير الأقدم، وبعدها يزامن آخر 100 فاتورة كل دقيقة إلى Firebase. تظهر آخر 20 فاتورة تلقائيًا في نموذج تسجيل الطلب، ويمكن البحث برقم الفاتورة.

## الاستخدام

1. افتح تطبيق **فواتير Paydo** وسجّل الدخول إلى Paydo.
2. اترك التطبيق يعمل؛ إغلاق نافذة Paydo يخفيها ولا يوقف المزامنة.
3. من قائمة **التطبيق** اختر **فتح تسجيل الطلبات**.
4. عند اختيار **فاتورة موقع** ثم **اختيار فاتورة** ستظهر فواتير Paydo.
5. للمزامنة الفورية اختر **مزامنة الفواتير الآن** أو اضغط `⌘R`.

للتشغيل أثناء التطوير: `npm start`. ولإنشاء تطبيق macOS: `npm run build:mac`.
